Cody personal

A private personal dashboard.

Cody personal is a local application for its owner's planning, learning, projects and reviewed information. The dashboard runs on the owner's Mac. This page describes its Google connection; it does not provide access to the dashboard.

About CodyPrivacy policyPersonal-use terms

Read-only Google access

With explicit consent, Cody reads selected Gmail messages and events on calendars the owner owns, so they can be viewed in the local My Day workspace. Gmail access includes message content and settings within the granted read-only scope. Calendar access is limited to owned-calendar events. Cody cannot send email, change messages or edit calendar events through these permissions.

Stored on the owner's Mac

Google credentials are stored in dedicated macOS Keychain entries. Selected message and event snapshots are kept in local private files. Read controls show source timestamps, coverage and failures. Account authorization alone does not prove that a read succeeded.

This is a personal-use application, not a publicly hosted account service. No Google sign-in, data upload or dashboard records are offered on these information pages.
